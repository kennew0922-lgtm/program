// コメント 1行コメント
/* コメント */ 複数行（ブロック）コメント
<script> ～ </script> JavaScriptを動かすための唯一のタグ
const 変数宣言。データを一時的に保存する箱を作ります。
let 変数宣言。データを一時的に保存する箱を作ります。
console.log() 出力。ブラウザの「検証ツール（コンソール）」に結果を表示します。デバッグの神。
document.querySelector() 取得。HTMLの要素（classやid）をJSで操作するために「キャッチ」します。
addEventListener() イベント。「クリックされたら」「キーを押したら」といった動作のきっかけを作ります。
function / => 関数。ひとまとめの処理に名前をつけて、いつでも呼び出せるようにします。
if / else 分岐。もし〜ならA、そうでなければB」と処理を分けます。
for / forEach 繰り返し。大量のデータを順番に処理したいときに使います。
fetch() 戻り値。関数の処理結果を外に返します。
return 外部のサーバーからデータを取ってきたり、送ったりするときに使います。
class / id JSからCSSのクラスを付け外しして、アニメーションなどを制御します。
